O que são requisitos de software?

A análise de requisitos de software é o processo de identificar, analisar, documentar e validar os requisitos do software

Precisamos entender quais são as necessidades e expectativas dos usuários e das partes interessadas envolvidas

Os requisistos de software são basicamente as especificações que definem o que o software precisa fazer para atender a esas necessidades, possuindo dois tipos principais de requisitos:
Funcionais e não funcionais

Requisitos Funcionais:
    Descrevem as funcionalidades e tarefas específicas que o software deve executar. Por exemplo,
    um sistema de gerenciamento de pedidos pode ter o requisito funcional de permitir que os usuários cadastrem novos pedidos. São requisitos que são o mínimo coerente para que o sistema atenda a sua premissa, ou seja, o minimo necessário para ele funcionar.

Requisitos Não Funcionais:
    Descrevem as características e qualidades que o software deve ter, como desempenho, usabilidade, segurança, entre outros. Por exemplo, pode ser que o sistema de gerenciamento de pedidos seja capaz de processar 1000 pedidos por minuto.

Regra fundamental:
    Toda tag com comportamento Display:"box" não pode ser inserido em tag com comportamento Display:"inline", somente o inverso.

A tag h são tags de cabeçalho, elas servem para títulos e subtitulos do conteúdo do <body></body>
sendo elas:
<h1></h1>
<h2></h2>
<h3></h3>
<h4></h4>
<h5></h5>
<h6></h6>

<p></p> -> delimita o espaço de um parágrafo, ela pode ter texto dentro de seu corpo.

<br> -> é especial, não possui fechamento, ela serve para quebra de linha (break row)

<hr> -> cria uma linha divisória horizontal

<span></span> -> ela não faz alteração visual imediata, mas ela é como uma caixa com orientação de linha, então ela delimita uma linha inteira e você pode estilizar especificamente o que há dentro dela através de CSS. É um container genérico em linha.

<div></div> -> é um container genérico com comportamento de bloco, ele delimita um espaço com altura e largura e pode receber qualquer elemento html dentro dela.

<b></b> -> para deixar o fragmento de texto, corpo da tag, em negrito (bold)

<i></i> -> torna o texto italico

<s></s> -> risca o texto no meio

<u></u> -> traça um underline no texto

<a></a> -> Torna o que esta dentro de seu corpo um link, precisa ser usado junto com o atributo href=""

<img> -> é especial, carrega uma imagem local (pelo endereço de diretório) ou externa por URL, utiliza-se o atributo src="" para o endereço e alt="" para indicar a descrição do que aquela imagem significa, como motores de busca não interpretam imagens, isso os ajuda a identificar

Tags Semanticas

<strong></strong> -> Da destaque no texto, mais forte que <b>, e permite mais personalização, diferencia nos motores de busca

<em></em> -> Da enfase no texto, torna italico por padrão, mas diferencia nos motores de busca

<del></del> -> risca o texto, como se o autor quisesse remover ou errasse ao escrever

<ins></ins> -> insere o texto, geralmente usada seguida de <del> como se fosse o autor corrigindo o texto

<small></small> -> torna o texto menor

<sup></sup> -> eleva o elemento de texto ao texto anterior

<sub></sub> -> coloca o elemento de texto abaixo ao texto anterior

<q></q> -> faz uma citação, acompanha o atributo cite="", e faz uma referência direta a um texto de outra fonte, geralmente para uma unica linha ou fragmento

<blockquote></blockquote> -> mesma coisa que <q>, mas para blocos inteiros de texto

<code></code> -> formata o texto para monospace (formatação padrão de IDEs), usado para inserção de trechos de condigo para leitura
